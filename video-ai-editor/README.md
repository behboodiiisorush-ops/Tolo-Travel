# Video AI Editor — زیرنویس فارسی خودکار

`subtitle.py` صدای ویدیو را با هوش مصنوعی (Whisper) به متن فارسی تبدیل می‌کند و زیرنویس را
با فونت وزیرمتن روی ویدیو می‌نشاند. روی همین کامپیوتر اجرا می‌شود و کلید API لازم ندارد.

## نصب (یک بار)
```
pip install -r requirements.txt
```
ffmpeg هم لازم است. بار اول مدل (حدود ۱٫۶ گیگ) خودش دانلود می‌شود.

## استفاده
```
python3 subtitle.py film.mp4                  # متن + ویدیو با زیرنویس
python3 subtitle.py film.mp4 --only-srt       # فقط فایل متن، برای اصلاح دستی
python3 subtitle.py film.mp4 --srt fixed.srt  # ساخت ویدیو از متنِ اصلاح‌شده
```
خروجی‌ها در `out/` ساخته می‌شوند: `film_fa.srt` (متن، با هر ویرایشگری قابل اصلاح) و
`film_captioned.mp4`.

روش پیشنهادی: اول `--only-srt`، غلط‌های املایی را در فایل `.srt` درست کن، بعد با `--srt` ویدیو را بساز.

## تنظیمات
| گزینه | کار |
|---|---|
| `--model small` | خیلی سریع‌تر، ولی غلط املایی بیشتر (پیش‌فرض `large-v3-turbo`) |
| `--words 5` | حداکثر چند کلمه در هر زیرنویس |
| `--pos 0.72` | ارتفاع زیرنویس (۰ بالا، ۱ پایین) |
| `--size 1.0` | اندازهٔ متن |
| `--audio voice.wav` | متن را از این فایل صدا بگیر، نه از صدای خود ویدیو |
