# متن صداها — «زنگ آخر ۴: زره‌پوش»

صداها با ElevenLabs (مدل v4) ساخته شدن و توی `voices/` هستن؛ همون صداهای قسمت ۳ برای هر شخصیت.
حالت خوندن داخل [ ] به انگلیسیه؛ ElevenLabs اجراش می‌کنه، نمی‌خونه. زمان‌ها از شروع فیلمه.
صدای رادیو (خط ۱۰) **همون فایل صدای مامان از قسمت ۳** است، عین هم — مثل یه ضبط.

## من (Danesh، کمی زیرتر در میکس)
```
[whispers] اون شب... [short pause] دیگه هیچ‌کس نخوابید.
```
```
[nervous] [determined] من بازش می‌کنم.
```

## سرباز (خشن، از پشت در)
```
[raspy] [weak] گوش کنید. [short pause] پشت سالن، توی حیاط... یه ماشین زره‌ای هست.
```
```
[raspy] [urgent] بگیرید. سوار شید و از اینجا برید.
```
```
[sad] [raspy] من دیگه نمی‌تونم بیام... [short pause] ولی یکی باید درِ حیاط رو باز کنه.
```

## آقای کاظمی (mohsen)
```
[surprised] [quietly] ماشین؟ سوئیچش کجاست؟
```
```
[whispers] [firm] پشت سر من. آروم.
```

## مهسا (Amitis)
```
[pleading] تو چی؟ تو هم بیا!
```
```
[shouting] [scared] بدو!
```

## کیان (Farshad، زیرتر در میکس)
```
[whispers] [scared] مامان؟
```

## کارت آخر (من)
```
[softly] [mysterious] اون صدا مامان بود... [short pause] یا فقط یه ضبط؟
```
